# HTML自動整形ツール

`html_formatter_tool.html` をブラウザで開くと使用できます。インストールや通信は不要です。

## 使い方

1. 「書式付きで編集」に文章を入力、または書式付きの文章を貼り付けます。元のHTMLを使う場合は「HTMLを入力」に切り替えます。
2. 文字を選択して、文字サイズ（8〜96px）・太字・斜体・下線・取り消し線・リンクを設定します。「書式を解除」で選択部分の文字装飾を解除できます。
3. 「整形する」を押し、表示を確認します。
4. 「HTMLをコピー」で整形済みHTMLをコピーします。編集後は、もう一度「整形する」を押してください。

文字部分を `<span>…</span>` で囲み、行の間に `<br>` を出力します。親子の文字装飾は一つのspanのstyleに統合し、spanを入れ子にしません。太字・下線などのタグも対応するstyleに変換します。保持するインラインスタイルは、文字サイズ・太さ・斜体・下線などの線装飾・文字色だけです。背景色（透明を含む）・font-family・vertical-alignは除外し、掲載先のサイトの指定を優先します。上付き・下付きの縦位置も引き継ぎません。URL・メールアドレスの自動リンクはチェックで切り替えられます。既存リンクは二重にしません。プレビュー内のリンクは移動しない設定です。

入力方法を切り替えると文章を引き継ぎます。その際、対応する書式だけのHTMLに変換します。画像・表の構造・外部CSSやclassによる装飾・スクリプトは保持しません。貼り付け元のアプリがHTMLとして提供しない書式は引き継げません。

入力内容はブラウザを閉じると消えます。必要なHTMLはコピーして保存してください。

## 正本・コピーの運用

- 正本は `000_master_data` です。改良はここに上書きします。
- 更新のたびに、更新後の正本一式をコピー作成日（日本時間）の `YYYY-MM-DD` フォルダへコピーします。
- 同日の再更新は、その日付フォルダのコピーも最新に更新します。過去の日付フォルダは変更しません。
